## 一、驗證範圍與檢驗方法

本次驗證使用 Python 自動化腳本執行語法解析、欄位比對、字元編碼校驗與結構檢驗：

1. **來源一致性（`sources.csv` vs `raw/S01.md`～`S08.md`）：**
   - 檢驗方式：以 Python `csv.DictReader`（採用 `utf-8-sig` 解析 BOM）比對 `sources.csv` 與 `raw/` 檔案之來源 ID、機構、主題、原文標題與 URL。
2. **Wiki 條目完整性（`wiki/` 10 篇條目）：**
   - 檢驗方式：程式遍歷 10 篇 Markdown 檔案，確認是否具備 `AGENTS.md` 約束之 9 大必要標頭欄位。
3. **文化小測驗三選一與答案有效性：**
   - 檢驗方式：正則表達式檢測 `- A.`、`- B.`、`- C.` 選項，並交叉比對 `答案：[A-C]\.` 是否完全存在於選項中，且與 `data/entries.json` 題目與解答一致。
4. **日語詞彙正確性：**
   - 檢驗方式：逐篇解析 Markdown 表格中之「日文、假名、中文」，人工語義與程式欄位結構雙重核對。
5. **資料庫完整性（`data/entries.json`）：**
   - 檢驗方式：Python `json.load()` 解析驗證 JSON 語法；檢查來源 ID 參照有效性、關聯條目 ID 閉環性。
6. **教學簡報（`slides/presentation.html`）：**
   - 檢驗方式：解析嵌入之 `slides` 陣列長度、鍵盤事件監聽器（`ArrowRight` / `ArrowLeft`）、投影片來源參照與 Wiki 條目主題對映。
7. **首頁整合與路徑（`index.html`）：**
   - 檢驗方式：檢查 `index.html` 之結構、資料整合架構（內嵌 `const entries` 設計）與簡報跳轉連結。
8. **相對路徑與內部連結：**
   - 檢驗方式：檢查 `index.md` 索引連結、`wiki/*.md` 互連關聯檔名存在性、簡報返回連結。
